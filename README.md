LeiloesTDsat
Sistema fictício desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas (TDS) do SENAC EAD, na Unidade Curricular 11 (UC11).

Descrição
O sistema foi projetado para auxiliar uma casa de leilões no cadastro e gerenciamento de suas rotinas e processos.

Tecnologias Utilizadas
JAVA & MYSQL
